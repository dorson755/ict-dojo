# ICT Dojo

An adaptive digital learning platform for ICT education.

Typing is the first learning domain. The architecture is intentionally domain-agnostic so Programming, Computer Science, Computational Thinking, AI Literacy, Cybersecurity, Digital Citizenship, and other ICT domains can be added without redesigning the core learning platform.

## Current build direction

The foundation is being established around learning domains, reusable skills, skill dependencies, assessments, mastery, progress, adaptive recommendations, domain-specific exercise types, and shared student identity/progression.

The first vertical slice will prove this architecture with Typing.
